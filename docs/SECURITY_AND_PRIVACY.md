# امنیت و حریم خصوصی

## داده‌های ممنوع

- شماره کامل کارت یا حساب
- رمز کارت یا بانک
- رمز پویا
- CVV2
- اطلاعات ورود بانکی
- Token، Secret، Keystore یا رمز امضا در Git

فقط چهار رقم آخر کارت در صورت نیاز محصول مجاز است.

## اعلان و پیامک

متن اعلان/پیامک داده حساس است. نباید در Logcat نسخه Release، گزارش خطا یا سرویس تحلیلی شخص ثالث به شکل خام قرار گیرد. نگهداری متن خام باید حداقلی، دارای دلیل روشن و قابل حذف باشد.

## فایل‌هایی که نباید Commit شوند

- `local.properties`
- `*.jks`, `*.keystore`
- فایل‌های رمز و Credential
- `.env` و فایل‌های محلی Secret
- خروجی Build و Cacheها
- دیتابیس واقعی کاربر و Backupهای حاوی داده مالی

## وضعیت GitHub

در تاریخ ثبت این سند، مخزن عمومی مشاهده شد. پیش از افزودن سورس اختصاصی یا هر داده حساس، بهتر است Visibility به Private تغییر کند. حتی در مخزن Private نیز Secret نباید Commit شود.
