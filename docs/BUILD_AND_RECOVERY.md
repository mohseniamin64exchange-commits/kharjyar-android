# بازیابی پروژه پس از تعویض ویندوز

## وضعیت فعلی این سند

سورس پروژه هنوز در مخزن نیست؛ بنابراین نسخه دقیق JDK، Android Studio، Gradle، AGP، Kotlin، Compile SDK و Min SDK باید بعد از دریافت سورس از فایل‌های واقعی استخراج شود و نباید حدس زده شود.

## چک‌لیست قبل از تعویض ویندوز

- خروجی ZIP کامل AI Studio دریافت شود.
- سورس با Git Commit و Push شود.
- مخزن Private شود.
- وجود Gradle Wrapper بررسی شود.
- تمام فایل‌های Source، Resource، Manifest، Test و Migration اضافه شوند.
- فایل‌های Secret و محلی حذف شوند.
- در صورت وجود Keystore، خارج از Git و در محل امن پشتیبان‌گیری شود.
- آخرین Commit Hash و نتیجه Build ثبت شود.

## بازیابی در ویندوز جدید

1. Git، Android Studio و JDK سازگار را نصب کنید.
2. مخزن را Clone کنید.
3. پروژه را از ریشه Gradle در Android Studio باز کنید.
4. SDKهای درخواست‌شده را نصب کنید.
5. `local.properties` را محلی ایجاد کنید؛ از Git دریافت نشود.
6. Sync Gradle را اجرا کنید.
7. `assembleDebug` و Unit Testها را اجرا کنید.
8. Instrumentation Testها را روی Emulator یا گوشی اجرا کنید.
9. تنها پس از تطبیق با معیار فاز دوم، فاز ۳ را آغاز کنید.

## متن پیشنهادی برای معرفی به هوش مصنوعی جدید

```text
این مخزن پروژه اندرویدی «خرج‌یار» است. ابتدا README.md و تمام فایل‌های پوشه docs را کامل بخوان. سپس سورس واقعی را بدون تغییر بررسی کن و اختلاف آن با PROJECT_STATUS و PHASE_2_ACCEPTANCE را گزارش بده. هیچ قابلیت جدیدی ایجاد نکن تا Build، تست‌ها، معماری Room/Hilt و وضعیت واقعی فاز دوم تأیید شوند. Secret یا داده بانکی را نمایش یا Commit نکن. بعد از گزارش منتظر تأیید من بمان.
```
