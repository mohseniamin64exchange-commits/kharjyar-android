# خرج‌یار (KharjYar Android)

اپلیکیشن اندرویدی فارسی برای مدیریت مالی شخصی، حساب‌ها، هزینه‌ها، درآمدها، انتقال‌های داخلی و در مراحل بعد، دریافت و تحلیل اعلان‌های بانکی.

> وضعیت این مخزن: فعلاً فقط مستندات بازیابی و ادامه پروژه در آن قرار دارد. سورس کامل پروژه هنوز از Google AI Studio دریافت و به GitHub منتقل نشده است. پس از در دسترس قرار گرفتن فایل ZIP پروژه، سورس باید بدون حذف این مستندات به مخزن افزوده شود.

## وضعیت فعلی

- فاز ۱: زیرساخت اولیه و معماری پروژه — انجام‌شده طبق گزارش AI Studio
- فاز ۲: لایه داده، Room، Repository، Use Case و تست‌های مربوط — انجام‌شده و Build موفق طبق گزارش AI Studio
- فاز ۳ و مراحل بعدی — شروع نشده‌اند
- برآورد پیشرفت کل محصول: حدود ۲۰ تا ۲۵ درصد

## گزارش آخرین اعتبارسنجی

طبق گزارش ثبت‌شده در AI Studio:

- `BUILD SUCCESSFUL`
- اجرای موفق `:app:testDebugUnitTest`
- موفقیت Unit Testها و تست‌های Robolectric
- بررسی تراکنش‌های Room، درج دسته‌های پیش‌فرض، رهگیری مانده و تبدیل تاریخ فارسی
- رفع تداخل بسته‌بندی drawableها و تأیید آیکون تطبیقی
- هشدارهای EGL/HWUI و پیام منسوخ‌شدن ashmem متعلق به شبیه‌ساز بوده و خطای برنامه محسوب نشده‌اند

این نتایج باید پس از دریافت سورس و راه‌اندازی روی سیستم جدید دوباره اجرا و مستقل تأیید شوند.

## شروع سریع پس از بازیابی سورس

1. مخزن را Clone کنید.
2. سورس ZIP خروجی AI Studio را در ریشه مخزن ادغام کنید.
3. فایل‌های محرمانه و محلی را Commit نکنید.
4. نسخه‌های JDK، Android Gradle Plugin، Kotlin و SDK را از فایل‌های واقعی پروژه استخراج و در `docs/BUILD_AND_RECOVERY.md` ثبت کنید.
5. ابتدا `assembleDebug` و Unit Testها را اجرا کنید.
6. سپس تست‌های Instrumentation را روی شبیه‌ساز یا گوشی واقعی اجرا کنید.
7. قبل از فاز ۳، وضعیت واقعی سورس را با `docs/PHASE_2_ACCEPTANCE.md` تطبیق دهید.

## قاعده اصلی ادامه توسعه

هیچ فازی بدون Build موفق، تست مرتبط و گزارش دقیق فایل‌های تغییرکرده کامل محسوب نمی‌شود. از بازنویسی بی‌دلیل معماری یا ممیزی کامل پروژه پس از هر تغییر کوچک خودداری شود؛ کارها باید به گام‌های کوچک تقسیم شوند تا مصرف مدل و احتمال توقف کاهش یابد.
